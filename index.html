Flower
Power

Desktop client for manga reading and anime streaming. Open-source, cross-platform.

Version 1.0.6
↓ macOS Binary ↓ Windows Executable

macOS Deployment

  1. Download the disk image (.dmg).
  2. Mount the volume.
  3. Move the Flower Power application to the Applications directory.
  4. Execute via Spotlight or Launchpad.
Security Notice: As a free open-source project, Flower Power does not use a paid Apple Developer certificate. macOS will initially flag the app as an "unidentified developer." This is completely normal and safe.

To bypass: Right-click (or Control-click) the application icon and select Open, then click Open again to launch.

Windows Deployment

  1. Download the executable installer (.exe).
  2. Run the setup file.
  3. Proceed through the installation dialogue.
  4. Execute via the Start Menu shortcut.
Security Notice: As a free open-source project without a paid Microsoft Publisher certificate, Windows SmartScreen may flag the installer as unrecognized. This is completely normal and safe.

To bypass: Click More info on the warning screen, then select Run anyway.
